# 面向单图上色质量评价的标签与描述调整建议

2026-10-15，依据主人提供的原始标注标准整理。**本讨论稿已被主人接受，正式内容已并入RULES.md及NR_legacy_only_v2配置／提示；以下保留讨论过程，不作执行入口。** 主人随后进一步明确：description只用自然语言，不用对象／等级标题；唯一旧底稿为reviewed_1_10000_clean.json，实验阶段AI结果全部取消资格。活动准备为02，01旧包已退役。未启动模型、未改写原始成品。

## 目标与标注证据

交付标签及描述应有待评价图片本身可见的缺陷依据。标注人员是否可查看GT，与最终模型是否使用GT是两个不同问题。建议保留现有GT与差分作为标注辅助，但不能仅凭“不同于GT”认定质量缺陷，也不能在最终描述中暗示某个不可从图片确认的原始颜色。

例如红衣GT对应蓝衣生成图：若蓝衣在生成图里自然、协调，只有颜色不一致不足以写C；不能把“相对GT变蓝”改成“衣服异常发蓝”来保留同一个标签。彩度差下降同样不能单独证明E2，需见到图片内不合理的发灰、寡淡表现。自然低彩度、阴天、雾景和风格不能只因低彩度被处罚。

GT参考差异及CV测量可以留在私有溯源／诊断，不混入最终训练描述。如果以后另有颜色还原度任务，另用对应的参考指标，不与本次单图质量C混用。

## 描述格式建议

保留已有字段id、severity、object、description，不增加冗长推理字段。

- object：可定位的对象或区域；不确定细部名称时用可靠大类及位置，不猜物体、材质、光源。
- description：位置／对象＋图片中直接可见的颜色或边界表现＋必要的视觉影响。一句短话，通常15—40字，以准确完整优先，不机械截断。
- id与severity由结构化字段表达，描述不必重复“C-L2”等代号。
- 不写GT、真值、参考图对比、“由某色变成某色”、“本应是某色”、“不如原图鲜艳”等不可从当前图确认的变化历史。
- 可使用“发灰、颜色寡淡、荧光感强、肤色泛紫、边缘串色”等当前表现，但必须真实可见，不能把参考差异改写成异常。
- 证据不足则不标，主要判断无法成立可用uncertain；不靠程序补物体、颜色或缺陷理由。

下面均为格式示意，并非对现有样本的新标注：

| 类别 | 描述示例 |
|---|---|
| B | 袖口的红色越过衣物边缘，侵入相邻手部。 |
| C | 天空呈大面积不自然的草绿色，与场景中的日光环境不协调。 |
| D | 左侧墙面及附近物体共同笼罩明显的黄绿色偏色。 |
| E1 | 前景草地绿得刺眼，呈明显荧光感。 |
| E2 | 人物面部和衣物颜色灰淡，整体显得寡淡失去生气。 |
| F | 多处颜色与光照关系不协调，画面呈明显人工涂染感。 |

示例词语不能作为标签自动触发条件，也不能照抄到看不到该表现的图片上。

## 建议恢复原始类别与分级语义

| 类别 | 主人提供的原始标准 | 与当前工作流的关系 |
|---|---|---|
| A | 全域上色失败，无任何有效色彩信息；无分级，命中总分1并覆盖其余判断 | 建议继续执行已确认冻结人工名单；不因这次描述调整自行重判A。严格原始定义与已冻结人工边界如需统一，单独明确，不让AI自行更改名单 |
| B | 颜色越过物体边缘；L1边缘轻微、可接受，L2明显侵入相邻物体，L3大面积扩散至整个场景 | 保持现有明确跨界证据，按本类分级，不用通用面积规则替代 |
| C | 颜色语义与内容不符；L1局部与光照／时间／天气冲突，L2多区域或整体组合不协调但非常识错误，L3违反固有色常识 | 应取消“与GT换色即C”。对光照／时间／天气的判断须有当前图可见依据，不猜隐藏场景；常见合理换色不因还原度不足而罚 |
| D | 区域或全图色调系统性偏移；L1单区域轻微可接受，L2单区域明显不可接受，L3全图统一偏移且不可信 | 应取消“只允许全图D”；区域内须有共同偏色依据，单物体固有颜色不同不能自动变成区域D |
| E1 | 过饱和；L1局部轻微不影响周边，L2明显刺眼或扩大影响邻近，L3全图异常、感官极差 | 应取消“相对GT更艳即E1”，图片内需有不合理过艳表现 |
| E2 | 欠饱和；L1局部轻微不影响周边，L2明显发灰或扩大影响邻近，L3全图异常、感官极差 | 应取消“相对GT更淡即E2”，自然低彩度不自动罚；E1/E2独立，可在不同对象共存 |
| F | 整体观感是否自然真实；L1仔细观察才发现，L2一眼可见且局部质量受影响，L3整体配色不像真实照片、可信度破坏 | 保留整体自然度判断，写清可见的颜色／材质／光照违和；C/D存在不自动追加F，不照抄同一条理由凑标签 |

严重度应采用各类别自己的锚点。当前提示里统一的“L1轻微、L2明显改变主要颜色、L3严重影响主体／大面积”不足以完整表达上表，尤其不能把语义等级C和区域／全图等级D混成同一面积规则。

## 两阶段流程的调整建议

维持已确认的训练／验证优先、人工A分流、16路共享、固定角色、4板／轮、4—8轮／会话、失败回池和断点约定。

1. RGB初标仍检查B/C/D/F：差分定位候选后，以生成图内可见的语义、跨界、系统偏色和自然度证据判定；不要求每个差分亮区都有缺陷。
2. 彩度二次仍重标E1/E2并审核其他四类：不仅改描述，还移除只由GT差异支持的C/E；按区域／全图D与原始分级重新审核。依据看板完成后输出六类最终完整列表，替换旧底稿。
3. 已有成品与High结果保留作待审底稿，不把它们直接认作新单图标准下正确的监督；逐样本保留修订差异，不增加第三个审核阶段或额外实验轮次。

## 对已准备产物的影响

源身份、冻结GT／A、图像哈希、任务分组和会话策略可复用。现有64张看板作为辅助图仍可复用，前提是采用本稿所述“参考差异不是质量标签”的约束。

若采用上述语义调整，需新建契约版本并更新RULES、AGENTS、配置、两类提示及各包prompt快照；旧任务包保留为旧口径、禁止误启动。当前包中含有旧C/D和通用分级规则，不能只改主提示文件而继续发送包内旧prompt。主控应对提示／契约版本作一致性检查，另存新准备版本。

程序可以查找描述中的GT／真值等显式词语并报告待修，但不自动删除词语后认定合格，也不根据缺陷词或图像统计自动增删语义标签。已准备产物尚未消耗新模型调用，因此这次可以先对齐标准再开跑。
