## 看板与标签

每张6行3列，保留当前大图布局；尾板可少。每轮4张同类型板，通常24个唯一样本。该批进入二次阶段时再读对应的4张彩度差板；两阶段8张板仍然只计24个唯一样本。S编号仅在一个任务包中有效，不含源路径、模型名、旧评分或旧标签。

RGB差分为逐通道clip(2×abs(生成RGB−GT RGB),0,255)，按GT尺寸对齐，用有符号数计算。亮区包含亮度、浓淡及换色变化，只帮助定位，不是C标签，差分颜色不是物体色。不继承旧AGENTS的A判断、旧阈值或“GT换色即C”规则。

彩度差继续复用当前signed ΔC*渲染与全量参照。红表示彩度增、蓝表示减，黑色不证明无错色。按主人最新要求取消黄色／橙色荧光候选轮廓及定位叠加，只展示纯差分，不让候选标记引导注意力。B导航保持关闭，不新增算法优化。渲染版本plain_difference_no_candidate_overlay_v1；旧带轮廓任务包仅作历史追溯，后续任务须重新生成看板，不能把旧板复制进新调用。

| 类别 | 判定及各自分级 |
|---|---|
| A | 原始标准为全域上色失败、无有效色彩信息，灰阶／单色／未渲染；无分级，命中总分1并覆盖其他判断。本次继续按已冻结人工名单执行，不让AI重新判A |
| B | 颜色越过物体边缘；L1边缘轻微溢出、可接受；L2明显溢入相邻物体；L3大面积扩散至整个场景。须见源颜色跨界，异色块、羽化、整物体换色不足以判B |
| C | 颜色语义与内容不符；L1局部与光照／时间／天气冲突；L2多区域或整体组合不协调、但非常识性错误；L3违反固有色常识。环境判断须有图中依据，不猜时间／天气；自然协调的合理换色不因不同GT标C |
| D | 区域或全图色调系统性偏移；L1单一区域轻微、可接受；L2单一区域明显、不可接受；L3全图统一偏移、图像不可信。区域偏色需要共同色调偏移依据，不能把物体本色／单个对象合理换色自动当D |
| E1 | 过饱和，独立于E2；L1局部轻微、不影响周边；L2明显刺眼或范围扩大影响邻近；L3全图整体异常、感官极差。相对GT更艳不能单独定标签 |
| E2 | 欠饱和，独立于E1；L1局部轻微、不影响周边；L2明显发灰或范围扩大影响邻近；L3全图整体异常、感官极差。相对GT更淡不能单独定标签，自然低彩度／雾景／阴天不自动罚 |
| F | 整体观感是否自然真实；L1仔细观察才发现；L2一眼可见、局部质量受影响；L3整体配色不像真实照片、可信度破坏。须有可见颜色／材质／光照违和，C/D不自动追加F |

各类分别按自己的定义和分级判断，可在同一对象或不同对象上并存。观察到一个问题后继续检查其余类别和区域，完整保留所有成立的缺陷。标签依据为生成图自身可见质量，GT／差分仅辅助。按每类自身锚点分级；分级仍是AI视觉判断，不代表已有人类准确率验证。

## 描述格式（正式要求）

保留结构化id、severity、object、description。description只写一句自然语言：图片中可定位的对象／区域＋直接可见的缺陷表现＋必要的视觉影响。对象名称自然融入句子，不使用对象标题、括号等级或类别前缀；禁止“外套（L2）：…”、“C-L2：…”、“外套：…”、“【过饱和】…”等格式。等级只放severity字段，类别只放id字段。

不写GT、真值／参考图对比、“原本是／本应是某色”“从某色变为某色”“比原图更淡”等不可从生成图确认的变化。程序不能仅删掉这些字眼就把描述变成合格监督。GT红衣、生成蓝衣且自然协调时，不保留C，也不能改写成“蓝衣异常”凑标签。

例如“外套颜色灰淡，袖口附近显得寡淡无生气。”是句式示例，必须在实际图中有证据才用。每条description充分写明对象／区域的可见问题，无15—40字限制；一条描述的句式约束不限制每图标签数。对象取本图实际可见内容，名称不确定可用可靠方位。详细标注清晰的L1/L2/L3，极其谨慎给无缺陷；重要不确定项记录uncertain。

## 二次审核与合并

二次会话先看本轮看板形成单图质量判断，再读取匿名prior_reviews.json核对旧标签，完整重标E1/E2并审核B/C/D/F。指定旧成品也不可信：必须纠正只有GT差异支持的标签，重写比较式／标题式描述，补足缺字段，允许新增、删除、改类别／严重度／描述；不能只润色措辞。初标新结果进入二次时也按同样六类标准检查。不增加第三阶段，不反复读图。

二次输出是六类最终完整列表，替换底稿而非数组并集。[]表示六类审核完成、无主要缺陷；null是未完成；uncertain单独保留，不作为可交付完成。程序只校验结构、范围、身份、依赖和覆盖，语义裁决由AI依据看板完成。旧标签、最终结果和差异分别保留。

## 会话与流式调度

共享全局上限16个在途调用，初标和二次不各开16路。每会话角色固定，一轮4板，先执行4轮，正常延长至8轮；任务不足可提前结束。按积压和实际吞吐决定新建哪种角色，会话中途不改职责。两阶段都可立即处理现成待办，初标完成后逐轮放入二次池，不等整批结束。

每轮结束并从文件验收后才领取下一轮，不预占4—8轮任务。使用显式conversation_id续接，不能用全局“最近会话”命令。每轮独立路径、独立输出，同一会话不并发提交两轮。首轮完整规则，后续固定短提醒加本轮路径；复用收益取决实际缓存计量，不承诺额度节省或认为模型获得了训练。

本机agy --help已确认支持--conversation和stream-json连续输入。具体流式消息协议、会话复用、usage缓存字段尚未实跑验证；离线准备不伪称调度器已经可用。CLI进程是否长驻与逻辑会话是否复用是两件事，必须以返回conversation_id校验。

## 失败、停机与断点

每任务／阶段状态独立：pending→ready→running→completed；二次依赖未完成为waiting_initial；补试为retry_pending，超过两次补试为needs_attention。任务领取要有唯一占用记录，过期占用不直接重复派发，先核对原进程与迟到文件。文件写入采用临时文件加原子替换，调度状态由一个主控更新。

CLI报错但实际文件完整合法，接收结果并保留native_status/native_error；合法已完成条目逐样本保存，不因为同包其他条目null而重做成功项。每次尝试新目录，补试最多两次，普通任务失败仅缺失样本回池，其他任务继续。初标已成功、二次失败只补二次。

2026-10-16主人最新规则：**会话遇到故障优先给会话发送“继续”来重试，3次都故障再重启会话，不要直接重启！**只有额度明确耗尽触发全停，在主人确认High恢复前不预检／恢复。认证401、地区／权限拒绝、连接失败／中断、超时及其他CLI错误严禁直接重启会话，应保留当前 conversation_id 向该会话发送“继续”，接续已加载的看板与底稿上下文重试写入，至多重试 3 次；3 次均故障才升级为重启会话（reset_session），更换新 conversation，未完成样本安全回池。基础设施故障不计入样本QA补试次数；每路新会话连续故障超过限额才隔离该路并显示原因，全部路隔离则状态为需处理，保留待标池。人工停止仍结束本队列在途调用并保存断点。

断点须含：源身份、阶段、依赖、任务ID、尝试次数、会话ID、角色、轮数、PID／调用ID、结果路径、领取状态和停止原因。恢复先读文件核对，再只派缺失；不把受中断的所有任务无条件回池。
