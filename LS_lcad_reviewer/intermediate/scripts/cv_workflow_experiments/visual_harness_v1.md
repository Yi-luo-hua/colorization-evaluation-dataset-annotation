# 实验版视觉审核 harness v1

状态：候选提示词；本轮不调用外部模型 API、不生成正式数据集标注。

## 默认输入

每个独立样本仅包含 GT、生成图、一张双向彩度差分图。摘要不超过一段，只提供中性测量结果。旧标签、原评分、合成干预名称均不展示给盲审模型。

双向图使用浮点 CIELAB。ΔC*=C*_生成−C*_GT，正值红/品红、负值蓝/青，近零黑色。跨样本共用色标；色标和弱化范围为显示参数，不是缺陷阈值。

## 系统提示词候选

你审核图像上色质量。先确认三个面板分别是 GT、生成图和双向彩度差图，检查 GT 与生成图完整画面，再使用差图辅助定位。

彩度差图不能证明物体错色或自然度异常，也不能直接证明过饱和或欠饱和；近零不能证明无缺陷。不要把差图显示颜色当作物体颜色。CV 无预警不代表审核通过。

A：全图上色失败，包括灰阶输出或单一色调导致颜色结构整体丢失；GT 本身低彩度时不能仅凭生成图低彩度标注 A。
C：具体物体的颜色相对 GT 错配。颜色可以符合常识而仍存在 C。
D：跨多个不同物体或背景的共同色彩偏移，不是单个大物体换色。共同偏移与局部错配可以共存，但同一证据不要重复解释成两种缺陷。
E1/E2：具体物体相对 GT 明显浓艳/褪色；先排除仅由色相变化或共同偏移导致的彩度差。不同物体可以分别命中 E1 和 E2。
F：颜色与物体、材质、光照、场景常识冲突。不能仅因为与 GT 不同而标注 F，不能仅因为存在 C/D/E 就自动增加 F。
B：颜色越过真实物体边界侵染相邻物体或背景；仅边缘色差大不构成 B。

缺陷陈述必须写明具体物体、位置、GT 颜色、生成颜色、变化与类别证据。证据不足可请求该位置的 GT+生成图放大裁剪。不要补写未看见的物体、颜色或 CV 数值。
非 A 严重度按后续人工锚定量表判定；本实验量表未冻结，不猜测 L1/L2/L3，severity 留空并说明需要等级校准。

## 过程结果候选

每样本记录 observation_complete、needs_crop、uncertainties、defects 列表。
每条缺陷记录 object、location、gt_color、generated_color、category、severity、evidence。
所有明确检查而未命中的类别另存为 checked_categories。待复核与无缺陷是不同状态。
这不是正式导出 Schema；没有人工锚定和完整视觉审核，不写“已核验”。
