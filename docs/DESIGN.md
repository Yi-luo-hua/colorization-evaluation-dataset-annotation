## 每类怎么处理

| 标签 | CV做什么 | AI怎么判 |
|---|---|---|
| A缺色 | 不再测A或筛查；prepare按冻结人工源身份分流 | 不进入AI；154条直接A命中、severity为空、评分1.0，其余类别不标 |
| B溢色 | 双侧近/远颜色同化原型只存内部诊断，默认不传B数值导航 | 看见邻接颜色跨轮廓侵染另一物体；短述谁侵入哪里，来源或跨界不清跳过 |
| C错色 | 同色相缩放残差、低彩度降权及稀疏候选轮廓 | 具体物体相对GT明确换成另一种可辨颜色，即使符合常识 |
| D偏色 | 网格共同变化、活动像素、增益解释及颜色组共同方向；仅候选 | 全图作为一个整体一起偏色，几个物体或局部共同变化不能当D |
| E1/E2饱和度 | 双向彩度差与局部候选，正红负蓝 | 具体物体过艳/褪色；灰白、灰黑、低彩度灰褐失色优先E2，不重复同物体C |
| F自然度 | 无直接语义判据 | 明确违背颜色常识、材质或光照；合理彩灯/反光不因不同GT自动标F，不因C/D追加 |

CV13 B原型要求近侧颜色向供色侧移动且强于远侧，再按源颜色保留、两侧趋同、GT双侧稳定性降权。gt_color_direction_support压低GT同色相深浅对比，低彩度参照保留近中性受染侧。require_retained_recipient_far_side再按max(0,1−远侧ab误差/近侧ab误差)降权：受染物体远处也大幅换色时，局部侵染证据减弱；只用于后续prepare。阈值沿用旧原型，无真实B正例金标准，b_boundary_evidence关闭；全图ab中位偏移补偿和旋转D提示不采用。

## 看板与提示词

默认6行三列、6组/张：GT、生成、双向彩度差；尾张可少。差分列最多两个稀疏橙轮廓提示留色色相候选，不是物体边界或C/B标签，黑色及无轮廓都不能证明无缺陷。匿名S编号，无原图位置、旧分数/标签。

High只读请求列出的PNG，每张一次，不查原图/manifest/源码、不裁剪/补图/复核。左右对应同一物体，每条只写一个可确认对象，局部不扩大；多色物体只写对应局部色块，部件名不确定用左右区域；右侧热图色不能当物体色。能确认才写色名，E1/E2可只描述相对浓淡，不强填GT/生成颜色；C需明确换色，拿不准省略。相对措辞已实跑，多色局部句尚未实跑，冻结恢复提示不改。

compact只含视觉S编号，初始null；模型自写reviews_gemini.json，数组表示六类已看，[]无主要缺陷，uncertain为主要判断不能成立。只允许B/C/D/E1/E2/F；固定A行由程序补入，只有A缺陷和checked_categories=[A]。六类行补六类完成字段，按两分支校验；不把未审样本写成[]。

## 调度与交付

默认High/compact/fast_single_pass，最多16独立agy进程、2看板/任务，完成即补位；多批共享总上限，各批自己完成即汇聚。每任务写独立文件，不并发写共享JSON或SQLite。单调用默认300秒。

只接收实际完整合法文件，CLI ERROR时仍可导入并保留native错误；null/非法文件待恢复，正常已齐任务不重跑。主人允许已登记标注问题/疑点用最新配置重新prepare定向重跑：不传旧答案、保留原输出，另存源身份对应的差异，不计新增唯一覆盖。real_batch_progress.py汇聚原批及恢复文件，完整结果写新目录。

结果保留全部GT合格输入。固定A缺陷/任务流只写A，不填写B/C/D/E/F阴性标签；非A的A未命中由分流决定，AI负责六类。人工A作者与AI六类作者在provenance区分。原元数据继承，未知人工账号不编造；未打分源保存标签及source_metadata_pending.json。原图、池、SQLite、正式导出和历史输出不覆盖。
