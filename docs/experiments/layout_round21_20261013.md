## 判断依据与限制

按实际文件覆盖、已知A控制、主要缺陷诊断及有效吞吐比较。AI标签数量/一致性不作准确率；同样输入的多次观察不计新数据。可靠逐看板读取日志不可得，不假造读取次数。
