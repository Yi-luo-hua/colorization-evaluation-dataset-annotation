# 第四轮CV优化与固定规则确认

2026-10-12；入口experiments/cv_workflow；活动配置cv_workflow_candidate_4。production_ready=false，严重度未校准。

## 实验设计

沿用第一轮11,428张训练/验证GT本底统计。训练GT彩度边界用于低/中/高彩度分层，不直接作为缺陷阈值。旧标签不作为本轮真值，测试集未参与调参。

|阶段|GT数|全局干预数|区域试验数|
|---|---:|---:|---:|
|开发与新留出|24开发+48新留出|2,880|2,160|
|后续固定规则确认|另48张新GT|2,256|1,440|

每张GT的干预互相关联，区间以GT ID聚类bootstrap（1,000次）。后续全局与ROI确认使用同一批48张GT，不能合计为96张独立参考图。基线固定为提交5322885的engine_v3.py，同一确认集逐例比较。

全局干预包含多个方向/强度的Lab平移、不规则和90%覆盖局部变化、彩度缩放、编码/线性RGB白平衡、曝光、JPEG、部分灰阶保留；后续再加两种单色、0.1倍彩度及90%覆盖通道增益。ROI检查彩度增加/降低/色相变化，面积0.1%、1%、5%、15%，最长边256/512，部分1%干预加JPEG。

## A：颜色结构整体失效

保留相对彩度/中心化色度结构收缩，加入亮度条件颜色结构：不相交像素交叉拟合ab(L)，检查生成图残差是否相对GT坍缩。GT有彩度像素的原色保留比例区分全图失败与局部褪色；忠实保留GT颜色结构的彩度缩放进入欠饱和复核。无彩色GT参考时不报A。

开发集搜索选出P95、GT曲线残差≥0.5、生成残差≤2、比例≤0.15、原色保留比例<0.005。后续结构保留排除采用既有0.03彩度比和0.5残差/截距边界，是标签定义的逻辑修正，未全部重新搜索。

首次48张留出只有灰阶与固定(6,9)色调两类A：96/96检出、零误报。随后更宽的单色压力验证暴露漏检，因此不能以首次100%宣称任意单色可靠。

## D：平移、通道增益、彩度缩放与曝光解释

平移分支结合4×4共同向量、一致/活动覆盖与活动像素≥0.95，减少大区域局部换色误报。另一分支拟合编码/线性RGB通道增益，采用全图Lab色度P98残差≤0.75、归一化通道跨度≥0.02、作用中位数≥0.5作为候选证据。统一曝光解释优先排除。

转换使用[sRGB标准传递函数](https://www.w3.org/TR/css-color-4/#predefined-sRGB)。颜色空间常数是定义，分类和搜索超参数在config.json/optimization_config.json。最优增益模型也可能拟合很差，必须同时读取残差。

首次48张留出D的F1：v3基线0.9411，仅严格像素覆盖0.9506，新增增益分支0.9791。曝光排除和结构保留逻辑另用新48张GT确认，最终规则不能冒充首次校准版本。

## 区域导航保留紧范围与扩展范围

初次扩展方案均值IoU提高0.7931→0.8490，但IoU≥0.25检出率从96.18%降到92.78%，JPEG明显回退，因此没有采用只保留扩展框的方案。

最终按原高阈值种子显著性排序；平台没有严格超阈值有效连通区域时回退到包含边界的阈值。每个ROI保留紧框/扩展框；扩展超过半幅面积回退；JPEG优先紧框。每类最多2个候选，不增加看板列数。

|新48张GT，1,440例|v3紧框|新主框|
|---|---:|---:|
|平均IoU|0.8096|0.9108|
|IoU≥0.25检出率|96.04%|99.79%|
|IoU≥0.5检出率|86.88%|97.43%|
|平均IoU聚类95%区间|[0.7969,0.8239]|[0.9028,0.9191]|

指标取同类候选中最好框，受每类最多2框影响；这是合成干预定位，不是物体分割精度。JPEG偏好基于文件后缀，PNG里已有压缩或JPEG来自无损处理时仍可能选错视野，两种范围供视觉纠正。
