# 第17轮：取消下游GT资格判断，重建实验基线

主人明确：GT初筛已经完成，标注阶段无需再判断GT能否参考。此前“传递GT状态以减少重复判断”的计划取消；正确实现是彻底移除下游判断机制。

## 新阶段职责

1. 上游GT初筛：gt_quality_gate.py独立筛查GT并冻结筛除清单。现有清单57张、0待定，日常标注不重跑。
2. 输入过滤/CV：workflow.prepare按冻结清单跳过源任务，保持原序号；只为已保留样本生成CV证据及六组看板。
3. AI标注：GT直接作有效颜色参考，评价生成图A/B/C/D/E1/E2/F。没有GT资格、弃用或缩减类别输出。
4. 汇聚/交付：每个进入标注的样本都有七类完成记录，完整保留；不会根据AI内容删除同GT模型样本。

当前配置CV10，annotation_contract=post_screened_GT_generated_only_v1。数值模型/阈值、High、自读本地PNG、自写JSON、双向彩度差、六组看板、16路滚动上限沿用；变化在阶段职责与输出契约。

## 已移除与归档

- 当前harness、IDE交接和START_HERE不再描述GT可用性判定或GT低彩度候选。
- compact只接受缺陷数组或生成图判断uncertain；展开后七类固定完整。校验拒绝旧范围/资格字段、缩减checked_categories及弃用决策。
- 导出不再按模型判断筛除GT、传播删除同GT样本或生成下游GT弃用文件。源元数据检查同样检查全部输入记录。
- 配置仅保留gt_filter指向上游清单，移除GT可靠性判定/候选阈值。engine删除仅用于下游GT资格提示的标记，A/D数值预测与证据不改。
- 旧资格契约不能新启动、克隆或导入到当前标注器；workflow.verify仍可只读核对旧来源哈希。要新实验必须重新prepare，不给旧manifest改个版本号继续运行。
- 第15/16轮一次性驱动/配置逐字节移入archive/rounds_15_16。历史报告添加明显提示，原报告/核心/文档另存[修改前快照](../archive/stage_boundary_20261013/snapshot_manifest.json)。历史模型原文件、候选及正式交付不回填。

## 重新编排

基线冻结后依次做生成图缺陷实验：A/E2的全域失败与局部残色；C/D的单物体换色与跨物体共同偏移；物体/部位GT→生成颜色grounding；必要的轻量双向彩度/局部证据；跨划分两模型的新GT确认与速度/滚动并发稳定性。

取消下游GT资格识别、GT状态重审和无参考/缩减类别方向。旧第15/16轮仍作为开发历史，不直接称新流程有效。未打分源保留完整标签，缺旧评分/模型/时间戳时旧严格候选延期，不造元数据或重跑视觉。
