# 第十轮：同GT相邻排列与批次大小

> 已完成阶段的历史记录。当前任务与默认流程查[STATUS](../STATUS.md)和[PLAN](../PLAN.md)；旧命令保留当时文本，一次性脚本现位于[归档索引](../../experiments/cv_workflow/archive/rounds_01_14/README.md)，不作为当前运行入口。

## 对照范围

采用活动CV8重新计算第九轮12张GT×两模型，共24例；这不是新独立留出。High、本地六组看板、四字段结果、E2优先和无有效GT彩色参考仅B/F均保持。

三组对照：

1. 原顺序：LCAD十二例后接Unicolor十二例，一个24例调用。
2. 相邻顺序：同GT的LCAD/Unicolor相邻，一个24例调用。
3. 相邻顺序拆分：按相同顺序拆成两个12例上下文，顺序调用，总耗时取两调用之和。

每张仍六行三列、六组。来源图像哈希、全部CV指标及候选按S编号完全一致；原图/生成/热力图/遥测顶栏逐像素一致，仅行序与对应行号位置改变。提示词规则相同，仅必要看板列表和当前批次候选ID不同。旧标注未复制，具体物体参考未提供给模型。

## 结果

| 对照 | High耗时 | 完成/范围 |
|---|---:|---|
| 原顺序24例 | 188.34秒 | 24例完成，正式格式与逻辑校验通过 |
| 同GT相邻24例 | 222.58秒 | 24例完成，正式格式与逻辑校验通过 |
| 同GT相邻2×12例 | 243.60秒 | 96.48+147.12秒，两子批与汇聚均通过校验 |

原顺序的S010/S022黑白旧照片均只B/F，S013/S014全图缺色仍A，无uncertain。S007/S019背景变化有区分，但风筝主翼和包装盒等主要对象仍有遗漏。Codex的诊断观察不是人工真值，不把标签项数量或AI之间一致性当作准确率。

相邻排列比原顺序本次慢18.2%，思考tokens19,638→23,721。A两例和B/F范围两例保持，但S007 LCAD仍红的围巾被误写为青蓝，与相邻Unicolor的描述一致；风筝主翼、包装盒遗漏未改善，另有物体识别错漏。拒绝相邻排列作为默认，不声称已经证实模型所有串样的机制。

拆分12例的两个顺序调用合计243.60秒，比原顺序整批慢29.3%，比相邻整批慢9.4%。这里是实际子调用耗时之和，不包括Codex在调用之间的分析停顿；原始记录保留时间口径。S003/S015风筝主翼换色开始标C，但S007仍红围巾又写成褪白、S008/S020包装对象仍遗漏；并出现设备被叫鼠标等实体误述。拆分也不设默认。

三个条件均保持S013/S014两个A和S010/S022两个B/F-only，均无uncertain。各条件的C/E2逐物体项分别12/16、13/9、18/17；多项不等于更准确。没有改回原始评分或标签，没有因为实验失败更换默认模型。

## 当前结论

采用的生产候选配置仍是CV8；High、六行三列六组、原样本顺序、整批单次调用保持。当前没有足够证据支持默认相邻配对或默认拆成12例；两种策略只作为实验入口保留。

下一步回到CV差分信息：重点检查等彩度换色及主要物体遗漏，可试单张总色度差热图与现有双向彩度图对照，不增加补图、逐图查找或长提示词。现有彩度双图/合成图和类别导航已经测试过，不直接重复升级默认。

上一轮148秒使用旧GT参考规则，本轮188秒使用CV8完整规则且为另一次调用，不能只据这个差异归因于规则。当前对照每条件先运行一次，记录实际波动，不声称稳定的倍数提升。
