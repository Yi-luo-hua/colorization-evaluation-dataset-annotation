## 采用依据

- 参数放配置；由统计/物理干预确定范围，冻结后另选新GT确认，不靠样本ID或旧标签写算法。
- 每次只改一个主要因素；保持样本、顺序、模型、任务拆分和队列上限，报告调用/墙钟、失败与恢复分别耗时。
- 物理控制、Codex/其他AI诊断、主人参考分开；AI一致性和Schema通过不当作准确率。
- 速度第一，明确主要缺陷即可，允许少量不完美；不重复全批追求一致，不增加查原图、补图、长报告或人工逐项批准。
