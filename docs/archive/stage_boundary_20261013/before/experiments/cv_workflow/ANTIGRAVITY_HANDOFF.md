# Antigravity 快速轻量标注协议 v4：compact文件

默认fast_single_pass，速度第一，允许微量不完美，逐批迭代。模型按主人指定gemini-3.8-flash-high。

## 只读看板，一次完成

只读START_HERE.md、review_request.json、review_template.json和请求列出的六组大看板。行首S001等是批次内匿名编号。禁止逐张查找/打开原始GT与模型图；禁止读manifest、任务池、数据目录、源码反查位置；禁止crop、补图、自写裁剪、运行--help、自写重复验证。不要看完看板再回头逐图分析。

每张六组，逐行对照GT/生成图/双向彩度差，单次完成后写JSON。彩度差正红、负蓝，黑色仍可能有等彩度错色，红蓝不是E1/E2自动标签。CV数字只辅助观察。

跨色组共同变化/较弱色组支持，是把GT相近颜色分组后等权统计的同方向变化，减少一个大物体主导整图统计；色组不是物体。支持很弱或结构保留scalar_gain接近0/为负时，优先检查具体物体错色，不能凭数值添加D。数值支持强也必须看见多个物体或背景共同偏移才标D。

## 轻量标签规则

- A：全图颜色结构失效；纯灰/单色失败，GT本身低彩度不罚。A为唯一缺陷，severity=""。
- A/E2：仍有可辨识物体间颜色差别时优先E2，不因整图接近灰阶直接标A；微量噪声或统一泛黄不算残色。CV9请求给出与GT对应颜色结构支持、系数/残差；“支持”时优先E2，“未确认”不等于A，仍看图。
- B：看得到具体物体颜色越界。小而模糊的边缘不追查。
- C：具体物体相对GT错配，即使颜色看起来合理。
- D：多个物体/背景共同偏移，单个大物体换色不直接归D。
- E1/E2：具体物体相对GT过艳/褪色；不同物体可并存。
- 主人明确的C/E2边界：主要褪色成浅灰白、没有明显换色相时优先E2；明显换色相才标C，不因单纯褪色重复追加C。
- 默认信任GT，拿不准仍使用；仅黑白且无有效物体颜色，或跨不同物体明显异常整体色偏、正常光照不能解释时判不可信。自然低饱和、阴天、夜景、夕阳、舞台灯光、雪景、水下环境、白灰/单色物体主导不单独触发；低彩度候选不是排除名单，不按比例凑数量。不可信GT直接弃用，不标对应生成图。
- F：看板明确可见的颜色常识/材质/光照违和，不因存在C/D自动追加。

优先明确可见的主要缺陷，少量难辨细节跳过，不穷举小物体、不反复推演。具体物体写清楚，evidence用一句短话。非A允许临时近似分级：L1轻微局部，L2明显改变物体主要色彩，L3强烈且影响主要主体/大面积；这不是已校准的严重度真值。

## 输出与自动结束

直接填写本地reviews_gemini.json（不存在时从review_template.json创建）。保持schema_version及reviews中的全部S编号；初始null是未看，逐行检查七类后替换成缺陷数组，无主要缺陷填[]。缺陷只填id、severity、object、description；例如{"id":"C","severity":"L2","object":"外套","description":"GT红色，生成紫色。"}。整批一次保存，不逐条反复修改，不在回复中返回标注JSON。主要判断无法成立才填{"uncertain":"简短原因"}，小细节看不清直接跳过。默认0补图。

object具体，description一句短话含GT/生成差异，建议35字内。允许同类不同主要物体分别记录。程序补固定元数据、完成字段和导出结构，不猜颜色或位置。保留Gemini原文件。不读历史分数/标签，不修改算法或正式数据。保存后只回复文件已保存，不写长篇总结，不再反复验证，也不等待人工补图或逐项批准。

新批次不可信GT填`{"exclude_GT":"black_and_white"}`，或`{"exclude_GT":"abnormal_global_cast","GT_evidence":"一句场景依据"}`。不检查或标注对应生成图，不用空缺陷数组、BF_only、NR表示弃用。程序从交付JSON/抽检包剔除同GT所有模型样本，另存原因。保留样本照常填缺陷数组或[]；旧冻结批次按其配置兼容历史格式。

可选的自动局部看板仅在明确开启非fast复核模式时使用；后台批量生成，仍不由Gemini打开原图，不依赖人工补图。默认轻量流程不进入该分支。
