# 第七轮：C/E辅助信号、看板对照与褪色边界

本轮采用两项改动：CV色相区域导航按剩余彩度降权；主人明确的“主要褪色优先E2，明显换色相才标C”写入后续提示词。活动配置升级为cv_workflow_candidate_6。默认仍为High、compact本地文件、六组看板、原双向彩度图，0补图；新双图和三色合成图只保留为实验。

原图、正式exports、任务池、SQLite及旧实验标签未修改。AI结果不是人工真值。

## 数值问题与改动

旧色相分量H=sqrt(max(0,Δab²−ΔC²))。生成图接近灰色时，RGB/Lab往返的微小残余彩度也会使H出现可见信号，影响“换色还是褪色”的导航。

新可靠方向信号为H×sqrt(min(C_GT,C_gen)/(max(C_GT,C_gen)+ε))，其中C为Lab彩度。在等彩度时保留原信号；接近灰色时降低方向差的权重，不减弱彩度损失本身。没有新增拟合阈值，保留已有显示deadzone、共享尺度、gamma和区域P95参数。

engine保留原hue_component，新增hue_direction及hue_direction_p90。regions.hue_signal选择hue_direction；区域类别仍叫hue_change，但它是数值候选，不是自动C标签。A/D候选规则未改，过饱和/欠饱和区域仍用正负彩度差。

## 主人确认的边界与实测

主人明确：主要褪色为浅灰白、没有明显换色相时优先E2；明显换色相才标C。该规则写入AGENTS.md、compact_harness、交接协议与START_HERE生成器，旧结果不回填。

最后一次调用只改提示词、保持原看板不变，用于验证新边界，不与新图混为一项改进。S006树叶、S011灰化滑雪服、S012左侧树叶开始使用E2；红色滑雪服变紫/蓝、绿色球场变紫仍为C。总标签集合相对旧版7/12一致，此数不是准确率。仍有物体细节错漏及C/E边缘情况，不能称为边界全部解决。

Codex查看看板后记录了GT可见物体观察，保存在内部GT_observations.json；它不是人工参考，也未提供给Gemini。参考餐盘案例用于说明A边界问题，没有修改模型原始结果。
