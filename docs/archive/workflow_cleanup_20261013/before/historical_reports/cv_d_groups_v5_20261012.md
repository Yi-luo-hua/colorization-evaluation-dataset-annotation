# 第五轮：全图偏色与大物体错色的区分

本轮回到CV实验，针对第四轮D提示与Gemini High的13个分歧。新增GT颜色分组等权统计及颜色结构保留约束，接入`cv_workflow_candidate_5`。原数据、正式exports、SQLite不变。参数仍为实验候选，Gemini结果是弱参考，不是人工真值。

## 方法和选参

旧规则用4×4网格共同偏移、像素活动覆盖和RGB通道增益，不能充分排除单个大物体主导全图数字。新规则保留旧候选、曝光排除及精确白平衡分支，在平移候选上补充以下证据：

- GT按Lab颜色分组：L间隔25、a/b间隔12，采样步长4，保留占比至少2%的组，每组等权。色组不是语义物体。
- 各组取生成图相对GT的ab变化中位数，再求跨组共同向量；统计同方向覆盖和投影P25，避免单一大面积颜色占据多数票。
- 保留原有彩度标量拟合。scalar_gain接近0或为负，提示原颜色结构严重塌缩/反转，应优先检查C或E2，不能仅因变化面积大就提示D。

36个真实样本按GT哈希拆成9张开发GT、9张留出GT；同GT的两个模型不跨集合。剔除3个A后，开发17例、留出16例。用已有24张合成开发GT约束：合成F1下降不得超过0.01，然后在真实开发弱参考上选择参数。实际搜索384组，60组满足合成约束。

选中的平移约束：共同变化≥2、方向覆盖≥0.5、投影P25≥2、scalar_gain≥0.2；仍要求旧D候选。搜索空间位于`experiments/cv_workflow/d_group_config.json`，选定参数写入`config.json`。颜色分组粒度本轮固定，未声称其已优化。

## 实际结果

“多提示/漏提示”以下均相对上轮Gemini High观察。它们不是已确认的误报/漏报。

| 数据 | 第四轮D | 第五轮D |
|---|---|---|
| 真实开发17例 | 一致命中3、多提示6、漏提示0 | 一致命中3、多提示2、漏提示0 |
| 真实留出16例 | 一致命中1、多提示5、漏提示2 | 一致命中1、多提示3、漏提示2 |
| 真实全体33个非A | 多提示11、漏提示2 | 多提示5、漏提示2 |
| 已有48张GT合成回归，2,064个非A | 检出806/816、误报5/1,248 | 检出806/816、误报4/1,248 |
| 新24张GT固定确认，1,032个非A | 检出404/408、误报0/624 | 检出404/408、误报0/624 |

新GT按先前GT彩度统计的三个分层各选8张，排除既往合成实验和视觉批次GT，不使用标签选择。冻结参数后进行47种干预，共1,128例。完整A→D串联在新集的误报从1例降到0；四例D漏检仍存在，不能称已解决所有边界。

消融对照：只增加scalar_gain≥0.2，真实全部多提示从11降到7；完整色组规则降到5。真实留出上两者同为3个多提示，所以色组额外收益目前只见于开发案例；保留为轻量数值导航，不宣称独立语义增益已证实。

36对图像、交替顺序、各重复3次测量：数值CV平均35.74→42.56ms/对，新增约6.82ms/对。不含读图、ROI、看板渲染和模型耗时。活动引擎36例判断与冻结实验结果逐项一致。

看板继续每张六组，原图路径和ID仅存内部manifest。顶栏改为“跨色组共同变化、较弱色组支持、结构保留”；快速请求保留6个数字，未增加局部补图或逐图读图。提示词解释色组不是物体，D必须看到多个物体/背景共同偏移。

同一36例的新全流程批次为`real_boundary_cv5_file_20261012`：Gemini High自行读取六张本地看板，直接填写本地`reviews_gemini.json`，程序一次导入并导出实验候选。运行结果见下方追加记录。

该批次已完成：36/36有效标注、29例有缺陷、7例无缺陷，实验候选通过正式格式与逻辑检查。A与本轮AI分歧0、D分歧6；相对旧High结果有8例标签集合变化。会话`abf852bb-4837-4378-87f7-22eaf789ffde`缓存包含6张看板图片，结果直接来自本地文件。

**速度目标未达成**：新调用248.95秒，旧36例High为157.70秒。输入44,231、输出22,206、思考14,543 tokens；旧调用分别27,790、15,745、9,053。虽然新增数值CV只约6.82ms/对，模型调用成本显著增加。本轮同时改变CV摘要/提示词及JSON文件输出方式，不是隔离A/B，不能归因于某一个改动，也不能用8例标签变化宣称精度提高。

因此第五轮只确认了CV候选的改善和新输出方式的完整运行；尚未优化好端到端速度。下一步应压缩High的推理/文件写入成本、用相同批量对照精简harness，并比较C/E辅助图。不能把跑通调用或产出更多标签当作提速结果。
