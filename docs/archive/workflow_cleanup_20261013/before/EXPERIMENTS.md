## 计时、样本与证据口径

- 并发墙钟不等于调用时长相加；第10轮顺序拆批244秒是两个调用之和，准备/分析停顿不计入。
- 第12轮全队列时间与逐批完成时间不同；第13轮两条件共享16进程环境，不是两个隔离吞吐试验。
- 图像对按模型计，GT按原图去重；重复条件、恢复尝试和历史锚点不计作新GT。
- 第12轮新增144张GT/288模型样本；第13轮新增36张GT/72模型样本，另24历史锚点。两轮近期独立新增观察合计360样本/180GT，不是已建立360例人工金标准。
- 合成控制、AI观察、主人参考是不同证据来源；AI一致性、Schema通过和真实语义准确率分别报告。
- 地区/连接/容量失败记录保留；恢复后新的attempt独立保存，不把失败当作显示/算法差异。
