## 1. 诊断与波动基线

复用第12/13轮已有数据作为开发诊断，明确标为已见样本。重点包含：

- 黑白旧照片、自然白灰物体、暗场但有明确蓝/红参考的GT。
- 明显异常整体色偏与正常夕阳/舞台灯光/雪景/水下环境对照，拿不准继续信任GT；不以排除数量或比例作为优化目标。
- GT有效彩色而生成图全灰/单色失败；仍保留肤色、衣物等颜色的严重褪色。
- 单个大物体换色与多个物体/背景共同偏移，保留D/C边界对照。
- 主要对象漏项及GT颜色误述案例，区分描述错误、缺陷类型错误和范围错误。

先统计已有两次原版复测，不为了追求一致性重复调用全批。必要时只对关键小集追加配对重复，并记录类别/范围、物体、颜色方向及严重度分别是否变化。65/96是已有类别集合/参考范围一致性，不作为准确率或新参数优化目标。

观察分层：已知合成干预可作物理控制；Codex看板观察及其他AI输出只作诊断；主人明确的标签定义是规则依据。没有人工真值的项目不报告人工准确率。

主人已重新明确：不可信GT直接筛掉弃用，不标生成图。无参考标签扩展计划取消。全部train/val/test的GT CV筛查及候选确认已完成，同GT全部模型样本自动排除；接下来只在保留任务上进行A/E2对照。后续GT筛查优化以减少特殊场景误排和混合色偏漏筛为目标，不追求增加剔除数量。

## 2. GT条件化的CV证据

沿用训练10,000张GT统计及验证GT资料，检查均值、分位数、灰阶像素比例、空间色度结构、ab(L)残差与颜色保留之间的关系。低彩度候选3.5214仍不能直接等于GT无参考。

拟评估的问题：现有特征是否能以较少信息区分无参考GT和自然低彩度；生成图残余颜色是否来自有效物体颜色结构；单色/灰阶失败与强彩度收缩是否可以得到更清楚的证据。具体新增特征、阈值及提示形式尚未确定，不把本页设想写成已实现分类器。

如果需要选参：

1. 从GT分布与已知干预确定搜索范围；参数放配置文件，不在算法里写场景ID或拍脑袋决策常数。
2. 按GT ID拆开发/留出，同GT两模型及全部干预同区；已使用样本不能重新称为新留出。
3. 搜索后冻结，在另选、排除历史GT的新集确认，报告误报/漏报和失败类型。
4. 只改一个证据/规则因素，与当前默认做相同图像/任务划分对照。先保持CV候选与视觉判断分离，不新增自动放行或硬性BF-only门槛。

候选通过数值控制后，才测试提供给视觉阶段的最短中性摘要。不把GT主色摘要、类别导航或更复杂热图的旧失败方案未经新证据直接恢复为默认。

## 3. 轻量物体颜色定位

优先试最小的观察/输出约束，确保具体物体、GT颜色与生成颜色来自正确图片列。是否增加位置或颜色字段需实验，不先把当前四字段契约扩成复杂表单。

继续自读本地六组看板、自写JSON、不返回标注正文、不打开原图、不补图、不逐条反复修改。微小模糊细节仍跳过；重点是清楚可见的主要物体，不以增加缺陷项数量作为改善。

## 对照与采用依据

- 同样本、顺序、CV/看板、任务数、High和队列上限；改变项明确列出，记录实际并发峰值。上限16不等于每个小批实际并发16。
- 记录调用均值/尾部、并发墙钟、准备与恢复耗时；模型服务错误单列，失败记录和原模型文件保留。
- 全量样本/字段/来源覆盖与正式契约通过是工程完成条件，不能替代语义正确性。
- 数值修改用已知干预报告检出/误报；视觉修改用有限独立看板诊断及新GT确认，记录改善和新退化。没有有效证据的改动只保留实验。
- 采用时比较速度收益、主要边界/物体错误和新问题，符合速度优先、允许小量不完美的要求；不要求难辨小细节全部正确。
