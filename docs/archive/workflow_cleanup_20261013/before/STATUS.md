## 已知问题

1. GT参考范围：把有蓝色座椅参考的机舱误当无彩色GT，或把自然低彩度场景过度跳过。
2. A/E2：仍保留肤色/衣物颜色的严重褪色图会被AI误判为全图失败；CV候选与视觉结论仍有边界分歧。
3. 物体/颜色定位：包装盒等主要对象遗漏、GT颜色误述、相邻物体描述混用。
4. 结果波动：同看板/同规则重复输出也有差异，AI对AI一致性不等于准确率。
5. 严重度尚未形成稳定参考锚点；当前L1～L3为临时视觉近似。
