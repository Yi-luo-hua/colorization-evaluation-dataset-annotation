# 标注步骤

本轮只打开任务列出的 S 图，沿用本会话首轮已阅读的定义和示例。相对路径从任务 Markdown 所在目录解析。读图失败时报告对应 S 编号。

对每张 S 图先通看前景、主体、背景，辨认光源、材质和本来就可能呈中性色的区域。再按以下顺序组织判断；可在同一张已打开的图上完成。

1. **全图先查 D。** 对照不同区域和材质，看它们是否共同向同一色调偏移，并核对光照解释和反证。记录仍呈正常色的对象。只有显著全局偏色成立时才关闭整图 E。大片区域异常不等于全图；一处正常肤色也不能机械排除任何 D。
2. **逐区域查 A。** 找出应有颜色区分、实际只剩近灰明暗的部分，再按全图面积定级。同处已判缺色就跳过该处 C 和 E；继续看其他着色区域和其余适用类别。
3. **定位 B。** 写清来源、受染处及可见联系。B 成立后继续判断受染区自身的色相、彩度和颜色分布。来源证据不足时仍可依据独立证据判断 C 或 F。
4. **分辨 C 与 E。** 同一局部先问色相是否合理。若浓淡变化就能解释异常，转查 E；若色相本身与场景冲突，判 C。E 只在全图允许且该对象尚有合理可辨色相时评定；在不同区域分别检查过浓、过淡。区分局部严重与大面积轻微。
5. **独立查 F。** 指出斑块、条带或突变的位置，检查形状能否由纹理、材质或光照解释。只要分布证据成立，可以和 B 或 C 并标。最后核对各类与各区域，保留每个有依据的轻微缺陷。

完成所有适用类别的检查。仅跳过一个区域时，继续检查其他区域。读图成功但证据不足时，记为未发现可确认的缺陷。结果直接写入本任务指定的文件。
