## V5 原始标签定义与严重程度锚点

| 编号 | 标签名 | 定义 | 严重程度锚点 |
|-|-|-|-|
| A | 缺色 (Missing Color) | 上色失败，对于可识别的对象和场景，本应能形成色彩区分的区域呈灰阶或近灰，不能区分出有效色彩信息，要排除合理光照和合理固有色的情况，如雪地。将缺色按照面积分为L1-L3。有一层偏色滤镜时要按照偏色严重程度打偏色标签；如果有局部染了色，也可以评价饱和度，错色，同样要排除合理光照，合理物体换色，全局滤镜影响。 | L1＜整幅画面50%小范围缺色L2 ≥整幅画面50%大范围缺色，但仍有可以辨认的上色区域  <br/>L3 全局缺色，无法辨认出任何有效上色的区域和物体 |
| B | 溢色 (Color Bleeding) | 物体的颜色浸染到其他物体上，且被浸染的物体颜色不合理（即并非合理换色）。分为溢出边界和跨越式溢出。跨越式溢出允许溢出物体和被浸染物体不相连，不强制要求说出边界。要求被浸染区域的颜色与溢出物体颜色相近。确认溢色后，仍继续评价受染区域的错色、饱和度、自然度。只要分别满足相应定义，同一区域可以并标。 | L1：轻微边缘溢出、跨越式溢出面积小，需要仔细观察才能发现，几乎不影响图片质量  <br/>L2：明显边缘溢出、跨越式溢出区域较多，一眼可辨认  <br/>L3：物体间严重的交叉串色溢出、上色混乱，显著影响图片图片质量，难以接受 |
| C | 错色 (Semantic Color Error) | 物体或区域颜色完全无法用合理固有色，合理光照解释，且不能用色彩的饱和度偏移解释，不再按照类型区分，而是按照面积大小区分。  <br/>必须有物体语义或场景证据支撑，合理的换色不标C  <br/>必须回答：这个物体为什么不能合理呈现这种颜色？  <br/>必备证据：物体类别、实际颜色、语义或场景冲突  <br/>缺色的情况不算错色。 | L1：在次要区域或小范围的错色，需要仔细观察才能发现，对图片质量的影响较为轻微  <br/>L2：主要区域、主要对象的小范围或次要区域的明显错色，对画面自然度有影响；较大范围的错色，但是需要仔细辨别；  <br/>L3：主要区域、主要对象、大范围的明显错色，导致画面上色完全混乱，画面极其不自然 |
| D | 偏色 (Color Cast) | 全局统一的滤镜式向同一色调偏移，按照偏移对画面自然度影响的严重程度区分L1-L3。如果画面中有依据的合理照明（包括室内灯光）能解释，则不判D，但是不能用相机导致的偏移解释（可以认为画面是肉眼看到的情况）。 | L1：难以用画面中有依据的合理照明解释的画面色彩偏移，但画面的色彩仍可清晰辨别，影响较为轻微。  <br/>L2：无法用画面中有依据的合理照明解释的画面色彩偏移，画面色彩明显受到影响，但仍能辨别色彩信息。  <br/>L3：完全无法用画面中有依据的合理照明解释的画面色彩偏移，画面色彩受到破坏性影响，几乎无法辨别有效的色彩信息。 |
| E | 饱和度异常 (Saturation Anomaly) | 只能在无显著的全局偏色时标注；如果物体或区域能用合理固有色或合理光照解释，不评价该物体或区域的饱和度异常；如果物体缺色，不评价饱和度。饱和度异常指的是局部的、物体的偏移，仅评价物体颜色在色相合理时的不合理的彩度偏移 | L1：次要区域或小范围的轻微过饱和/欠饱和，肉眼可接受，不会明显影响图片质量。  <br/>L2：次要区域或小范围的明显过饱和/欠饱和或大面积区域的轻微过饱和/欠饱和，会较为明显地影响图片质量。  <br/>L3：多个区域/主要对象/大面积的严重过饱和/欠饱和，严重影响图像质量。 |
| F | 自然度 | 图像中存在无法由可见的物体材质、纹理、结构或光照合理解释的颜色分布异常，例如同一表面内部出现不规则颜色斑块、碎片化着色、非自然的条带或突兀的颜色过渡。  <br/>明确F必须指出不真实感具体来自哪里，颜色是怎样分布异常的。  <br/>必须回答：具体哪种颜色分布或过度破坏自然感？  <br/>必备证据：例如对象内部无依据的彩色斑块、图物色带、碎片化颜色组织 | L1: 需仔细观察才发现  <br/>L2: 一眼可见，局部区域质量受影响  <br/>L3：关键主体或大范围的着色连贯性被严重破坏，整体**颜色分布**完全不像真实照片，可信度破坏 |

## 各类的检查顺序与关系

完整判断顺序为 D → A → B → C/E → F。以下关系适用于你判断整张图时的推理，本次具体写哪些类见任务要求。

- **D 与 E。** 对照分处画面的不同区域和材质，看它们是否共同向同一色调偏移，并寻找能解释偏移的可见光照及仍呈正常颜色的对象。确认显著全局偏色时，整图跳过 E1/E2。轻微 D 不自动排除 E。大片区域偏移和一处正常颜色都需结合全图解释。
- **A 与 C/E。** 区分合理灰白、仍有可辨色相的低彩度、以及实际缺色。只在实际缺色的同一部位跳过 C/E，仍检查其余着色部分。A 按确认缺色范围占整张图的比例定级。遇到局部缺色，将位置自然写入对象和描述，以供后续对照原图。
- **B 与 C/E/F。** 先寻找颜色来源、受染部位及可见的浸染联系，再分别评价受染处的色相、彩度和颜色分布。跨越式溢出可以发生在不相接的物体之间。B 可以与 C、E 或 F 共存，各类需要有自己的依据。
- **C 与 E。** 在同一部位先判断色相合不合理，再判断浓淡。色相和场景或物体语义有明确冲突时判 C。物体仍保持合理可辨色相、但彩度显得异常时查 E1/E2。E2 要求争议对象自身仍可辨出色相。
- **F 与其他类别。** 独立评价颜色分布。具体指出异常的斑块、碎片、色带或突变，以及它为何与可见的光照、材质、结构或纹理不符。有独立证据时可以与 B、C 等类别并标。

## 保留清楚的轻微缺陷

每张图看完前景、主体和背景后，再有意识地扫一遍小物体、物体交界和物体内部表面。检查下列细节，关注范围小但轮廓、颜色或分布特征可辨的问题。

- **B 溢色。** 沿相邻轮廓看浅色或中性物上的局部染色。对隔开的相似色块，找颜色从来源落到受染物的可见联系。轻微、窄小的浸染有明确来源和受染部位时也应标记。
- **C 错色。** 单独看小物体、衣物或物件的局部、裸露皮肤和作为次要元素的对象。核对少见颜色是否仍可由合理换色、光照或反射解释。可见语义冲突足够具体时，局部也应标记。
- **F 颜色分布异常。** 看连续表面内部有无小块无依据的串色、碎斑、突兀边界或条带。即使整图自然，只要局部的颜色分布有清楚异常，也应标记。

轻微、面积小或整图观感尚可并不妨碍 L1 成立。对象名称拿不准但部位看得清时可用可定位的位置。证据仍无法确认时按实际观察判断，不用模糊猜测凑标签。检查完当轮指定的每一类和全部可辨认区域后，确认没有成立的标签才填空数组。第一、二轮的空数组只说明当轮负责的类别没有确认命中。

## 结果文件格式

结果文件是 JSON 对象，键为本任务的真实 S 编号，值为该图的缺陷数组。每条缺陷只写 id、severity、object、description 四个字段。id 使用 A、B、C、D、E1、E2 或 F。severity 使用 L1、L2 或 L3。description 写对象或部位的可见颜色异常和必要影响，使用自然句。

先读对应的格式示例及实际结果文件的骨架。示例中的 EXAMPLE_ 编号和观察是虚构的，实际只填任务里的真实 S 编号。保留骨架中的所有样本编号。读图失败的样本保持 null，并在回复中报告编号。正常完成后只回复“文件已保存”。只修改本任务指定的结果文件。
