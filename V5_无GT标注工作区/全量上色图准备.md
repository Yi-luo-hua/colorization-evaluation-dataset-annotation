# V5 全量上色图标注准备

使用 Train、Val、Test 的 LCAD 和 UniColor 生成图，共六个来源。唯一身份为划分、生成模型和图像编号。所有实际生成图均入队，人工或历史标注不带入模型。备包默认每包 10 张，使用 Gemini 4 Hydrogen High，最多 16 路。各包按相同随机种子重现，源图、源图哈希和真实身份留在主控端。

离线准备检查六个目录的图片容器及 SHA-256，把样本、批次和状态写入 queue.sqlite3，冻结提示词和模型配置，并生成首批 16 个匿名 PNG 任务包。剩余任务按领取批次生成。模型每次只收到上色图、本轮完整提示和该轮需要的普通标注 JSON。采用试验验证的四条消息：D/A/B、C/E1/E2/F、七类独立复核、同会话对照终标。第三轮检查等级并复扫空标签。

## 入口

- split_pass_full_prepare.py prepare 只建库并备包。--source-root 指向持有数据集的原项目目录，--run 指向持久化主控目录，--packets 指向单独的匿名任务目录。--starter 可调整离线预生成包数。
- split_pass_full_prepare.py status 输出同一队列内的状态和图片数。
- split_pass_full_prepare.py run 使用同一组目录、模型和 --agy 路径。--limit 可限制本次领取的任务包数。每个批次沿用分轮执行器的原生会话、读图与 JSON 验收，按批保存。已有通过的阶段与已完成批次可续跑。此轮仅执行 prepare 和 status。

最终 JSONL 按真实样本键导出模型终标。模型输入的图片编号保持匿名，历史和人工标注不作为底稿。实验指标只用于预估用量，不能当作全量质量结果或账户额度换算。


全量看板由 split_pass_board.py --run 提供，默认地址为 http://127.0.0.1:8948/。它只读 SQLite 队列和阶段回执，显示数据范围、已验收图数、活跃批次与待续接批次。
