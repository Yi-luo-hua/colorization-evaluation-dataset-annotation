# V5 无 GT 上色标注工作区

更新于 2026-11-24。接手 agent 先读本页与《试跑方法.md》。单轮 1,000 张已归档，后续标注包采用同一会话两轮派发。

历史试跑、原始结果及人工样例对照见 [V5 试跑索引](../experiments/timeline/20261121-20261124_v5_annotation/README.md)。

## 文件与职责

- 规则.md 是备包时采用的类别定义。模型读本.md 与 examples/ 维护 26 张有标签的生成图示例。变更典型图时同步修改图、卡片和对应规则。标注步骤.md 是每包实际使用的观察顺序。
- prepare.py 先发布示例.md 和匿名 R 图。首轮确认通过后，才发布任务.md、格式示例.json、匿名 S 图和输出路径。主控在 local/task_index 保存编号映射。
- turns.py 从原生会话日志核对图片附件和回复顺序。两个阶段都核对原 conversation_id。第二轮允许并行打开 S 图，每张图分别产出七类结论。
- validate.py 核对交付编号、七类状态、等级、缺陷字段与命中一致性。实际读图凭证、判断准确性和人工裁决另行核对。

## 已确定的判定

D 先看全局照明，A 逐区域判缺色，B 追踪浸染，C/E 区分色相与浓淡，F 独立评价颜色分布。A 按面积分 L1–L3，同一区域已缺色时跳过该处 C/E。B 可以与其他类同区域并标。正常读图后，七类逐项填 `hit` 或 `clear`。证据不足或按规则跳过整类时，均填 `clear`。确认存在显著全局偏色时，E1 和 E2 均填 `clear`。

## 两轮派发

1. 新 agy 会话先收到示例.md。模型读完定义和全部 26 张 R 图，再回复 `V5_EXAMPLES_READ`。执行器核对成功读图媒体回执及确认回复。
2. 首轮通过后，执行器生成任务.md、格式示例.json 和 S 图，用同一会话 ID 发送第二轮。模型读完格式示例后，把结果直接写到文件。验收要求该轮格式示例的完整读取和全部 S 图的媒体回执都早于对应 JSON 写入，并检查七类状态与样本身份。
3. 阶段缺项在原会话补试。中断后从保存的阶段续接，两个阶段分别保留回执。每包标注 10 张，仍使用旧 SQLite 队列和最多 16 路执行器。

格式示例从过去 22,768 条全量交付中的已完成记录分层随机抽取，覆盖无缺陷、单类与多类三种情况。原缺陷类别、等级和证据保留。A 状态使用旧交付的冻结名单分流口径，其余类别沿用旧验收记录。源编号留在 examples/格式示例来源.json，公开任务包只包含匿名范例的结果数组。26 张典型图继续作为视觉判断示例。

入口是 `run1000.py --agy <agy 路径>`。看板由 `supervise.py` 提供，地址为 http://127.0.0.1:8947/ 。额度检查由 `quota_watch.py --agy <agy 路径>` 支持。新运行用 `local/two_turn1000`。原单轮归档位于 `local/single1000`。

手动校准时，可以先运行 `prepare.py <任务目录>`，按示例轮提示发送 `[V5 示例轮] 读取 <示例.md 的绝对路径>。`，要求读齐全部 R 图后回复 `V5_EXAMPLES_READ`。随后运行 `prepare.py <任务目录> --conversation <原会话 ID> <生成图路径...>`，程序核验首轮后才生成任务.md 与格式示例.json。正式批量派发统一走执行器。

## 40 张人工盲审

离线入口为 [V5_40张人工盲审.html](local/blind40_20261121/V5_40张人工盲审.html)。只展示打乱顺序的匿名生成图。每张确认后自动保存到当前浏览器，全部审核后导出 JSON。结果按 H 编号关联 `local/blind40_20261121_key.json`，映射在盲审完成后用于对照。

样本包括全部 12 张 A-L3、3 张 E2、10 张旧 E2-L2/L3 而本轮无缺陷、10 张其余随机无缺陷，以及 5 张 C/F 并标。三个抽样组排除了已定向抽查的图片。该样本用于查找错误类型，组内数据只按各自的抽样口径解释。
