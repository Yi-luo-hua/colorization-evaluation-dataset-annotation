# A类：依据主人前200张人工标注校准

## 权威与适用范围

主人明确要求以人工标注为准。前200张的10个人工A：8、42、63、101、102、122、161、164、166、194，全部作为A正例保留。AI此前依据“只要可辨一点色调便排除A”给出的6条改判建议及101的边界判断已撤回；其观测和像素统计仅保留历史，不作为人审问题清单。

本文件是对当前人审口径的工作性解释与后续特征设计草案。原11.2标准快照、人工答案、金标准导出及既有图像均保留；未在生产流程部署数值门槛。

## 从正例归纳的操作性定义

**A缺色：整幅图像仍以黑白或近灰阶为主，整体彩度极低，有效上色基本没有建立。微弱整体色调、少量局部残色及微小通道差异可以存在，不单独排除A。**

“完全没有任何可辨色调”不能作为本批人审的硬门槛。122、194说明带有低强度整体暖色或黄绿色罩仍可判A；8、164说明少量局部残色仍可判A。不是把明显彩色且颜色错误的图都归A。

A与E2的候选边界：A强调整体有效上色基本失败；E2强调已经存在可评价的物体或区域色彩，但彩度不足。最终边界由人审锚点校准，不以这一句抽象定义反向否定人工标签。A仍不分级，命中后其余类别不适用。

## 候选指标与作用

| 指标 | 作用 | 使用限制 |
|---|---|---|
| 全图平均/中位C* | 衡量整体彩度水平，是A候选的主要依据 | 会被大面积黑白背景稀释，也会被浅色罩整体抬高；不能单独分类 |
| P95/P99彩度 | 观察较高彩度部分，较最高像素值稳健 | 小于所用分位尾部面积的有意义区域仍可能被忽略 |
| 原始最高彩度 | 提醒是否有局部高彩度像素 | 噪点、压缩及极小区域可抬高，不能一票否决A |
| 中等/较高彩度区域面积与最大连通区域 | 区别少量残色、孤立噪点与较大有色区域 | 彩度阈值和面积阈值都需结合人工正负例拟合，不能预先拍值 |
| 分块或语义区域彩度 | 防止主体或局部有效色彩被低全图平均值掩盖 | 当前仅计算4×4粗分块，尚非物体分割 |
| 全局色罩与剩余颜色变化 | 区别一层浅黄/浅绿罩色与实际空间颜色差异 | 当前用减去a*/b*全图中位向量后的残差作粗代理；不能独用，否则可能误伤真实单色物体 |
| 颜色的空间/语义结构 | 判断不同物体/区域是否形成有效颜色区分，是灰阶边界的视觉辅助 | 人审158与194表明必须保留空间语义观察；目前没有经过验证的自动语义特征 |
| GT原有彩度及生成/GT彩度比例 | 辅助区分自然低彩度场景与上色信息缺失 | 相对损失大也不必然为A，比例也不能单独分类 |

彩度采用CIELAB的C*=sqrt(a*²+b*²)，不是RGB最大通道差，也不是HSV饱和度。RGB通道差只作像素诊断，不能作为缺色标签门槛。

## 当前数据证据

只使用前200张中的187张GT可用样本：10张人工A、177张非A，其中73张有E2，3张为E2-L3。没有读取封存评测标签来设标准。

- 人工A的平均C*为0.39—5.45，P99为1.53—7.99；这些是样本范围，不是已验证门槛。
- 194（A）：平均C*=5.45，P99=7.65；87（E2-L3）：平均C*=2.62，P99=48.05。只看平均值会把有明显局部色彩的严重欠饱和图与A混淆。
- 101（A）：最高C*=20.48，但C*>20仅占1/65536个像素；其P99=5.16。最高值不适合一票否决。
- 194（A）的C*>5比例为77.31%，主要反映低强度整体色调；不能把所有微弱色调都算有效彩色覆盖。
- 158（非A，D-L2/E2-L1/F-L2）：平均C*=2.34，P99=7.65，仍处于上述A范围内。已对照其原图与生成图，显示平均值与高分位联合也不足以完整刻画人工边界。
- 若只是取本批A的平均彩度上界，会同时覆盖5张非A（58/59/87/158/173）；再加入P99上界仍覆盖158。不能用10个正例的极值拼出正式分类器。

## 后续使用顺序

1. 先以全图低彩度筛出A候选，保留强度连续值，不直接给标签。
2. 联合高分位、局部区域强度与面积、颜色空间分布、GT上下文，检查是否只是浅色罩或少量残色，还是已有可评价的局部有效上色。
3. 将人工A与严重E2、自然低彩度非A一起校准。只有10个A正例，暂不固定数值阈值，也不把本批拟合表现当泛化准确率。
4. 保持10个人工A的权威性。模糊案例向人审标准对齐，而不是让旧“绝对纯灰”规则覆盖人审。
