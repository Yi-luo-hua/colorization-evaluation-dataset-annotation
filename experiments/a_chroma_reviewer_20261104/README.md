# A缺色：大量图片快速人审与两参数校准

本地页面：[http://localhost:8092/](http://localhost:8092/)。2026-11-04 为主人建立，判断权属于人工；全程不改Label Studio及生产标注。

## 本轮数据

从旧工作流22,768条已完成结果中，沿原600张的GT分区规则只取开发分区。封存分区11,312条不参与筛选；再排除原600张所对应的全部GT身份（开发分区590条结果）。实际计算10,866张原始生成图，图像哈希与源记录逐张核验，0读取错误。

两个特征与前200张分析完全一致：float32 RGB [0,1] 经OpenCV转CIELAB，`mean_C=mean(sqrt(a*²+b*²))`，`var_ab=Var(a*)+Var(b*)`，总体方差ddof=0。原图不裁剪、不增强、不变色。派生缓存存于本目录`local/features.sqlite3`，原库只读。

宽松初筛得到4,115条候选，分层选取首轮600张：核心疑似92、近邻214、边界234、低均值对照60。这些筛选窗是收集正反例的采样条件，不是最终A判据。页面优先显示核心疑似，再显示近邻、边界及对照；不显示旧类别、拟合预测或数值特征，数值可按需展开。

600个生成结果身份唯一，对应558个GT组；同GT的不同模型结果可以同时入选。预先按GT SHA-256分组划分训练485张、验证115张；GT组交叉为0，验证标记不在判断界面展示。原600张所用GT组与本轮无交叉。新候选GT未另做全量人审质量筛选，本页判断不直接扩充六类金标准。

## 快速判断

- 每页24或48张；点击图片定位，按1判A、2判非A、3待定，判断保存后焦点移到下一张。
- 左右方向键切换，空格放大，双击图片也可放大；放大图可对照GT，继续按1/2/3判断。
- 勾选多张或全选本页后批量标记；Ctrl+Z或“撤销上次”恢复上一个操作。撤销仅针对本页最近一次保存的操作，不会清空历史。
- 页面每次判断都等待本机保存成功，不将未审核默认为非A。“未审核”筛选的本轮队列在翻页前固定，已判卡片不会突然挪位；切换筛选或刷新后重算剩余项。
- 页面重开自动读回SQLite。每次保存同时另存JSON备份；所有变更在SQLite events表留历史。待定可稍后筛出来重判。
- 审完点击“结束本轮并拟合函数”。有未审核项时仍可查看阶段性拟合，但页面明确显示未完数量；待定不参与训练或验证。

## 两个参数的确定

固定函数形式：

```python
def is_A(mean_C, var_ab):
    return mean_C <= mean_C_max and var_ab <= var_ab_max
```

仅拟合`mean_C_max`和`var_ab_max`两个阈值。原187张人工开发标签作为训练锚点（10 A、177非A），加入本轮训练组的确定人工判断。算法枚举训练样本观察值构成的二维门槛，采用二维前缀计数最大化平衡准确率；并列时依次选择误报更少、漏报更少、较紧的门槛矩形。未标与待定完全排除。

本轮验证组答案不参与门槛搜索，仅用来展示混淆矩阵、精确率、召回率和平衡准确率；缺少正类或负类时相应指标显示不足，不造0分。验证来自富集筛选池，反复查看仍属于校准内验证，不是原封存评测集、全量缺陷率或工作流独立成绩。

首次新判断前不产出最终阈值。人工结束一轮后可保存完整JSON函数、阈值、训练/验证样本身份、输入哈希、标签版本及混淆矩阵。新标注变化后需重新拟合，历史拟合文件完整保留。任何函数都不自动替换生产工作流。

## 启动与文件

```powershell
python experiments/a_chroma_reviewer_20261104/start.py
```

启动器创建独立隐藏pythonw进程，仅监听127.0.0.1:8092，不依赖当前终端；日志在`local/logs/`。当前运行服务与Label Studio独立。

- `local/manifest.json`：冻结候选、图像身份和两组划分；存在时不重抽。
- `local/features.sqlite3`：开发分区派生特征缓存。
- `local/judgments.sqlite3`：本轮人审判断及逐次事件；不是Label Studio数据库。
- `local/judgments_backup.json`：最近一次完整判断备份。
- `local/fits/`：每次拟合的独立快照；`latest_fit.json`为最新结果。
- “导出我的判断”可以另存本轮标注JSON。

`prepare_candidates.py`只做原图读取和数学特征计算，无模型调用。`verify.py`在独立临时数据目录检查API保存/重开、批量修正/撤销、无效请求拒绝、拟合独立于验证答案、待定排除及完整一轮拟合。浏览器的测试判断仅写`local/browser_test_20261104/`，不会混入主人正式判断。

已完成浏览器实测：1/2/3快捷键、Ctrl+Z、刷新持久化、24张批量保存及撤销、放大/GT对照、拟合结果显示、390px窄屏无横向溢出。截图与验证记录均在`local/`，不把这些检查当成人工标签质量验收。
