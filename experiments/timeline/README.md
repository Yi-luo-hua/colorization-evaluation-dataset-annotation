## 溯源方式

- 按阶段打开对应目录的 README，先找报告或统计，再按样本身份回到清单、原图、模型结果或人工定稿。用 split/model/image_id 或 source_sample_key 跨批次定位，批内匿名图号只在该批内使用。
- 本次建立按日期排列的导航目录。运行、配置、Label Studio 和历史回放会引用原始路径，因此留存材料仍存放在原目录。
- 11 月 14 日清理了旧主交付、旧 5000 任务包、退役预备包、旧 CV 和早期审阅中的 14,406 张编号生成看板。对应历史路径和哈希可能仍出现在日志或报告里。样本原图、运行库、标注、正式导出与冻结清单仍可查。
- 七类人工标准集的 600 张、A 单类快审的另一组 600 张、Train/Val 的 141 张近灰候选各有独立清单。

项目其他目录及历史整理记录见 [目录职责](../../docs/ORGANIZATION.md)。
